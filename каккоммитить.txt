если в репозитории есть изменения которые ты не добавил к себе на комп локально,
то перед коммитом выполни:
git pull origin master

после делай это
git add .
git commit -m "Описание"
git push -u origin master

в случае если хочешь проигнорить и стереть изменения в репозитории, то после коммита
выполни:
git push -f origin master
